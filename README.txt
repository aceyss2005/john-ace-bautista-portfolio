# John Ace Bautista — IT Professional Portfolio

Personalized website for John Ace Bautista, 3rd-year BS Information Technology student at Northeastern College. Expected graduation: 2028.

## Included
- `index.html`, `style.css`, `script.js`: editable, responsive website
- `certificates/`: three uploaded PDF certificates and two Microsoft Copilot learning certificate screenshots
- `resume.pdf`: privacy-safe version of the uploaded resume PDF; personal phone number and location line removed
- `README.txt`: publishing and editing instructions

## Preview locally
Open `index.html` in a web browser.

## Resume
The website's Download Resume button points to `resume.pdf`. The uploaded resume's phone-number row and location row have been removed from the PDF image; the professional email remains. Review the output before publishing.

## Publish with GitHub Pages
1. Download and extract the ZIP package.
2. Sign in to GitHub and create a new repository, for example `john-ace-bautista-portfolio`.
3. On the new repository page, choose **Add file → Upload files**.
4. Upload every file and folder inside the extracted portfolio folder. Make sure `index.html` is in the repository's top/root level, not nested inside another folder.
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch `main` and folder `/ (root)`, then click **Save**.
9. Wait a few minutes. Return to **Settings → Pages** and open the published URL displayed there.
10. Test the site on desktop and mobile. Check all certificate links and click **Download Resume** to verify the PDF opens/downloads.

## Keep editing
- Personal details and content: `index.html`
- Colors and layout: `style.css`
- Mobile navigation: `script.js`
- Certificates: `certificates/`
- Resume: replace `resume.pdf` with an updated privacy-safe PDF using the same filename.

## Privacy checklist
- Avoid publishing your personal phone number, home address, full birth date, government IDs, or private information.
- Review certificates and resume before uploading.
- Only share professional links you want to be public.
